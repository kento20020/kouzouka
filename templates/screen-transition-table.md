方式の意味

| 方式 | 意味 | 使う場面 |
| --- | --- | --- |
| push | 今の画面の上に積む | 一覧→詳細など、普通の前進 |
| replace | 今の画面を置き換える | 完了画面、戻らせたくない手順 |
| reset | 全部捨てて置き直す | ログイン成功、ログアウト |

## チェックリスト

- [ ] 全ての遷移に方式（push／replace／reset）が書いてある
- [ ] 完了画面（送信完了・決済完了）は replace になっている
- [ ] ログイン成功・ログアウトは reset になっている
- [ ] 最初の画面で戻ったときの挙動が書いてある
- [ ] 入力途中で戻ったときの挙動（確認／下書き保存）が書いてある
- [ ] 同じ画面を二重に push しない対策が書いてある
- [ ] 通知・リンクから直接来たときの入口と、そのときの戻る先が書いてある
- [ ] 未ログインでログイン必須の画面に来たときの挙動（returnTo）が書いてある
- [ ] ログイン済みでログイン画面に来たときの挙動が書いてある
