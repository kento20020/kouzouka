# 状態×イベント表（Step5）

> 使い方：行に状態、列にイベントを並べ、**全マスに「どうなるか」を書きます**。
> **空欄は「仕様が決まっていない＝バグ」です。** 「無視」も仕様として書きます。

## イベントの集め方

| 種類 | 候補（使うものを列にする） |
| --- | --- |
| ユーザー操作 | タップ・連打・戻る・入力・キャンセル・画面回転 |

## 文章の仕様にする（EARS）

1マス＝1文で書けます。

- `＜状態＞の状態で、＜イベント＞が起きたとき、システムは＜どうする＞。`
- 例：`送信中の状態で、送信ボタンが押されたとき、システムは何もしない。`
